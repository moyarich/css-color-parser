## Use in your project

:::code-group

```sh [Install]
npm install @moyarich/css-color-parser
```

```ts [Parse a color]
import { parseCssColor } from "@moyarich/css-color-parser";

const color = parseCssColor("#635bff80");
console.log(color);
```
